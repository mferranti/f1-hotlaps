# Phone-only app; decoders copied from f1-telemetry-ea, not shared

F1 Hotlaps needs to record the player's Laps from the F1 game on the same network, and nothing else: no account, no server, no desktop client. So it is a single Expo app that receives UDP Packets with `react-native-udp`, decodes them in TypeScript, and stores Laps in SQLite on the phone; export to JSON is the only way data leaves the device. The F1 25 and F1 26 decoders are copied from `f1-telemetry-ea/packages/telemetry-protocol` into `src/protocol/` rather than shared as a package, because a cross-repo package would bring back the monorepo, workspace, and release tooling this app exists to avoid, and the two apps can then change their decoders independently. The cost is that a fix in one repo must be ported to the other by hand.
